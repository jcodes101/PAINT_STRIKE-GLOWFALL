# PAINT STRIKE: GLOWFALL

[▶ Play PAINT STRIKE: GLOWFALL](https://jcodes101.github.io/PAINT_STRIKE-GLOWFALL/)

PAINT STRIKE: GLOWFALL is a colorful first-person paint shooter set in an open arena. Customize your Canvas Runner, join an online lobby, and compete in Survival free-for-all or Team Deathmatch.

## Gameplay

- Shoot paint projectiles and use movement, jumping, and cover to outplay other players.
- In Survival, fight every other player and be the last one standing. In Team Deathmatch, help your team reach 25 eliminations first.
- Shoot down flying power balls to gain abilities such as speed, invisibility, a rapid-fire sprayer, rockets, or high-damage shots.
- Visit trade stations to exchange a power and restore your health and shield.
- Customize outfits, suit colors, hats, masks, gun skins, and back bling.

Matches in the browser build are online multiplayer and require at least two players.

## Controls

| Action | Keyboard and mouse |
| --- | --- |
| Move | `W` `A` `S` `D` |
| Look | Mouse |
| Jump | `Space` |
| Fire | Left mouse button |
| Toggle invisibility | Right mouse button |
| Trade at a station | Hold `E` |
| Pause or leave a match | `Esc` |
| Show Team Deathmatch scoreboard | Hold `Tab` |
| Switch spectator view after elimination | `V` |

## Run locally

Open `project.godot` in Godot 4.7 or later and run the project. Online matches need a running game server; see [MECHANICS.md](MECHANICS.md) for match rules, networking details, and local multiplayer test instructions.
